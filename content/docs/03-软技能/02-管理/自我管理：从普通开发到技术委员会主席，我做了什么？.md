## 我的八年轨迹

我是 2017 年参加工作的，最初担任 Java 开发工程师，有个组长带着我。2019 年跳槽换了一家公司，一直就职到现在。

刚入职时我是 Java 小组长，带着两个实习生。那两年是我技术突飞猛进的时候。当时公司软件部规模不大，也就二三十号人，我所在的业务组共 8 个人，算上我只有三个后端。

在巨大的交付压力和带新人的双重责任下，既有来自上层的项目截止日期，也有实习生层出不穷的疑惑解答压力。我被迫从后端开发延伸到了 Linux 服务器运维、部署，所有的事情都得自己扛。这种在无人协助的压力下强行解决问题的经历，让我的能力有了肉眼可见的提升。

两年后（2021 年），在我工作的第 4 年，我担任了业务板块后端组长，组员扩充到了 7 个人。又过了两年（2023 年），公司软件部开始大规模扩张，部门达到了一百多号人，我也被升职为架构师。

说实话，当时我挺纳闷的，不知道架构师到底该干嘛。为了搞清楚这个岗位的边界，我去考了一个系统架构设计师证书，这才对职责有了系统性的了解。到了 2025 年，公司成立技术委员会，由 5 位技术成员组成，我担任了轮值技术委员会主席。

以上就是我粗略的履历。我希望把这些年的晋升心路历程写出来，既是复盘，也是分享。我打算分三篇来聊：第一篇关于自我管理，第二篇是团队与部门管理，第三篇是参与公司决策。

## 自我管理

关于管理，我非常喜欢德鲁克在《卓有成效的管理者》里的一句话：“一个人能否真正管理他人还有待进一步证明，但管理自己始终是可以的。”

这句话对我启发很大。管理者最开始不该想着怎么管人，而是得先管好自己。让自己强大起来，才能成为团队的杠杆点，给组员赋能。

### 核心原则

回忆这些年，我一直遵守以下几条原则：

**做自己擅长的事：** 这点非常重要。每个人都有长处，你得自己去探索。我推荐大家看一本书《如何找到想做的事》。找到长处并结合职业规划，你才能比别人进步得更快。只有当你在某条路径上走得比别人既快又稳时，你才具备了管理团队的资格。

**洞察立场的沟通：** 关于沟通，我一直受用《人性的弱点》里的一句话：“如果成功有诀窍的话，这个诀窍在于洞悉他人的立场，并能够同时兼顾自己和他人的立场。” 沟通和谈判本质很像，你既要传达你的观点，也要分析别人的观点，最终牵引双方达到共同的目的。

**抹平阶级感的谦虚：** 一定要记住，岗位是公司赋予的标签，不代表你比组员高人一等。千万不要拿着鸡毛当令箭！岗位的不同只是为了区分工作内容，大家都是一条船上的兄弟，不分彼此。这里我推荐蓝斯登原则：在你往上爬的时候，一定要保持梯子的整洁，否则你下来时可能会滑倒。

**真诚的微笑：** 这也是从《人性的弱点》里学的，非常实用。微笑能让你更易走近他人，让人觉得随和平易近人，别人才愿意跟你多沟通。否则，你在推进工作时会处处受阻。这不需要献殷勤或附和，而是真诚地对待他人。

**跨学科思维：** 管理是个综合能力，不仅仅靠技术，还需要心理学、沟通技巧这些软技能。主动去阅读管理、心理学、方法论相关的书籍，能让你在管理上更加游刃有余。

**持续学习：** 苏格拉底说过：“人懂得的东西越多，就会发现自己不知道的事情越多。” 保持好奇心，现在借助 AI 学习一切你想知道的内容，真的非常有趣！

### 人生架构
![](https://stellar-img.oss-cn-shenzhen.aliyuncs.com/obsidian/Generated%20Image%20February%2009%2C%202026%20-%204_45PM.jpeg)


自我管理可不止在职场，还关乎整个人生。受知行小酒馆播客节目《你一生的财富》启发，我也在实践这套理念：

**健康：** 健康是一切财富的基石。

它包括身体、心理和情绪的健康状态。在管理上，我坚持每周去四次健身房，有氧无氧结合；饮食则保持低油低盐低辣，注重营养均衡。此外，克制烟酒等不良习惯、保证充足睡眠、定期体检以及寻找工作与生活的平衡（包括必要的休假）都非常关键。

**时间：** 时间强调的是质量和自主性。时间财富并不等于闲暇时间。要警惕帕金森定律，即“工作会填满所有可用时间”。除了运用番茄工作法和深度工作理念，我还会利用通勤、等待等碎片时间进行思考。在明确优先级的同时，要学会对无价值的请求说不，并灵活应对突发状况。

**精神：** 精神代表内在的满足感。这关乎平和感与心理韧性。我通过写日记和独处散步来进行内省，并针对特定主题进行深度反思。通过学习新技能保持好奇心，同时提升情绪识别与调节能力。最重要的是减少不必要的自我批评，在接纳不完美中探索个人价值观。

**金钱：** 金钱是实现目标的工具。它是经济基础与财务安全感，而非最终目的。要定义自己的“富足线”，理解自由在于资源与欲望的平衡。在达到满足点后，从“赚更多”转向“用好财富”，通过提升核心技能、复利思维和风险分散来实现财务的长期稳健。

**社交：** 社交是优质的情感连接。这里我给不了太多建议，因为我的社交基本是 0。除了定期跟父母联络外，我基本没有什么社交活动。这可能是我目前的短板，但也给了我大量的独处时间。

## 总结

自我管理是一件持续一生的事情，极其重要。

传统工业时代的逻辑往往把人当作流水线上的螺丝钉，只要求做好一件事。这种模式对个体成长其实很不友好，容易导致思维僵化。反观那些优秀的 CEO，无一例外都是全才。这足以证明，想要向上突破，跨学科思维才是关键。

最后，我再次强烈推荐大家去找到自己的长处与价值观。如果你还没找到，去读读《如何找到想做的事》。我通过这本书找到了自己的定位：我非常适合信息技术领域的管理工作。这事我做起来非常轻松，因此每天有大量闲暇时间用来学习，从而形成了一个正向飞轮。希望你们也能找到自己的飞轮。
